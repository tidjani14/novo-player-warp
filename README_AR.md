# مشروع NOVO PLAYER 3.8 + Cloudflare WARP عبر MASQUE

هذا المشروع يعيد بناء أرشيف Smali المفكوك المرفق، ويضيف زر WARP داخل التطبيق. زر WARP يطلب صلاحية Android VPN ثم يشغّل نفق Usque/Cloudflare WARP عبر MASQUE (HTTP/3 CONNECT-IP). يستدعي المحرك `VpnService.protect()` على مقبس QUIC قبل الاتصال، فيمر بث NOVO نفسه عبر النفق من دون دوران اتصال MASQUE داخله.

## طريقة البناء في GitHub

سكربت التجميع ينشئ `apktool.yml` من `apktool.json` الموجود في المصدر المفكوك قبل إعادة البناء، لأن Apktool CLI يحتاج ملف YAML.

1. أنشئ مستودعًا جديدًا وارفع **كل محتويات هذا المجلد** إليه، مع ملف `NOVO_PLAYER_v3.8(40)_base_src.zip`.
2. من GitHub افتح **Actions** وشغّل `Build NOVO Player with Cloudflare WARP MASQUE` عبر **Run workflow**. يمكن تشغيله تلقائيًا كذلك بعد دفع تغييرات للمسارات المحددة.
3. بعد نجاح البناء، افتح تشغيل workflow ونزّل artifact باسم `NOVO-PLAYER-MASQUE-APK`.
4. لو لم تضبط أسرار التوقيع، ينتج APK موقّعًا بمفتاح CI مؤقت للتجربة. للتحديث المستمر، أضف GitHub Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.

يبني `scripts/build_masque_engine.sh` ربط Go/gomobile من مراجعة Usque المثبتة، ثم يبني `scripts/build_github.sh` التطبيق. يثبت GitHub Actions Go وJava 17 وGradle وAndroid SDK وNDK تلقائيًا.

## أين يظهر التحكم؟

يظهر زر **WARP · OFF/ON** في أعلى يمين الواجهة الرئيسية وصفحتي تعديل/إدارة القوائم فقط، ويبقى بعيدًا عن صفوف القوائم وأزرار التحكم السفلية. يمكن الوصول إليه بريموت التلفاز عبر الأسهم ثم OK/Enter. الضغط عليه يبدّل الاتصال والفصل مباشرة في خدمة الخلفية، من دون فتح شاشة إضافية أو Toast؛ والـdispatcher الشفاف مثبت أفقيًا كي لا يسبب دوران الواجهة. سيظل Android يطلب موافقة VPN عند أول تشغيل، كما يعرض إشعار خدمة VPN الدائم الذي يفرضه النظام.

## صلاحية WARP بحسب MAC التطبيق

توجد ملفات الـAPI ولوحة الإدارة في `backend/IBO/`. استبدل `index.php` الموجود على خادمك بالنسخة المرفقة، وانسخ معه `vpn_access_store.php` و`vpn_access_admin.php`. انسخ `vpn_access_config.example.php` إلى `vpn_access_config.php` واضبط `admin_password_hash` لكلمة مرور قوية قبل نشر اللوحة. افتح `vpn_access_admin.php` وأدر الأجهزة؛ يسجل الـAPI أي MAC جديد كـ **ممنوع افتراضيًا**، ويضيف `vpn_allowed` إلى استجابة المصادقة الحالية. يقرأ التطبيق هذه القيمة ويمنع إنشاء نفق VPN ما لم تكن مفعلة لهذا الجهاز. تبقى صلاحية قوائم التشغيل ومنطقها كما في API الأصلي.

تأكد من أن لوحة الإدارة تعمل عبر HTTPS، واضبط `store_file` على مسار خارج مجلد الويب إن أمكن. يستلزم تغير السماح/المنع أن يحدّث التطبيق بيانات المصادقة؛ أما النفق الجاري فلا ينقطع فورًا لمجرد إطفاء الصلاحية من اللوحة. التحكم عبر MAC حاجز إداري أساسي ويمكن تجاوزه في نسخة تطبيق معدلة؛ لا تعتبره نظام DRM قويًا.

## تنبيهات مهمة

- تم رفع الحد الأدنى إلى Android 7.0 / API 24 بما يتوافق مع بناء مرجع Android المستخدم للمحرك. هاتفك Android 11 متوافق.
- محرك MASQUE يُبنى من مراجعة Usque مثبتة مع رقعة حماية المقبس في `warp-addon/third_party/`؛ وهو مشروع مستقل غير رسمي عن Cloudflare.
- النفق يستخدم نقطة MASQUE الافتراضية المسجلة، دون فحص منافذ أو اختيار مسار ذكي أو رجوع تلقائي إلى WireGuard. لا يمكن استنتاج البروتوكول من `warp=on` وحدها.
- لا يستثني هذا البناء UID الخاص بـNOVO من الـVPN. يحمي مقبس MASQUE عبر `VpnService.protect()` قبل QUIC، ويمرر بقية اتصالات التطبيق داخل النفق.
- يبني workflow مكتبات Android الأربع: ARM 32-bit وARM64 وx86 وx86_64.
- سيتم توقيع الناتج بمفتاح جديد. لا يمكن تثبيته كتحديث فوق نسخة لها توقيع مختلف؛ احذف النسخة القديمة أو استعمل مفتاح التوقيع الأصلي إن كان متاحًا لديك.
- التطبيق الأصلي مفكوك من APK وليس مشروع المصدر الأصلي. هذا يعيد بناء الموارد وSmali ثم يضيف شاشة WARP؛ ليس استعادة للمصدر Kotlin/Java غير الموجود.
- نفق WARP يوجّه كل حركة الجهاز IPv4/IPv6 عبر `AllowedIPs = 0.0.0.0/0, ::/0`.
